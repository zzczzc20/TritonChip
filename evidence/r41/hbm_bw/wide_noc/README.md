# Wide NI and real mesh boundary

The core and slice network interfaces now accept DATA_W and BYTE_W parameters. Their defaults reproduce the exact historical 216-bit payload. At 512-bit data and 64 byte enables the payload is 720 bits, including unchanged address, five-bit requester tag, four-bit source, atomic opcode and scalar 64-bit compare fields. Responses carry the full data width and requester tag. Width consistency guards refuse mismatched data/mask/payload geometry. Existing macro definitions and all unconfigured tile/top widths remain unchanged.

`tools/r41/wide_noc_tests.py` passes eight configurations: 64/512 data bits, zero/two registered link stages and ready/backpressured destinations. Each sends 768 transactions through the real three-node tnca_mesh and routers, using the actual core NI and three slice NIs. All request data bytes, masks, addresses, opcode/atomic fields, source and tags are checked at the expected home. A canonical concatenation checks packet encoding independently of the matching decoder, including exact historical bit layout at 64 bits. Every response data bit is checked against its outstanding tag, with no duplicates or undrained requests permitted. Thirty-two finite requester tags are reused only after response delivery.

The no-stall cases accept 768 requests in 768 consecutive cycles at both widths and link-stage settings. With the deterministic destination stalls they accept the same count over 859 cycles. The two-stage 512-bit case drains after 878 cycles. These prove a logical single-source injection/receiving-stage boundary at one full-width packet per cycle; they do not establish physical timing, cache-service throughput, all-to-all contention, effective HBM traffic or board bandwidth. The endpoints are echo registers rather than NUCA caches. A write's echoed data must not be counted as useful operator traffic. Both width guards are separately tested; the final guarded implementation also passes a 32-request saturated smoke test.

The next step is integration through the actual cache/home service and a compact vector LSU. Current tile/top wrappers still instantiate 64-bit defaults. Atomic fields are transported correctly, but execution of a wide atomic through the home is unqualified. The 720-bit packet and all receive-side capacity/ownership behavior must be screened physically in the complete candidate. No FPGA image run or card access was involved.
