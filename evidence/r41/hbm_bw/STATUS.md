# HBM bandwidth status

Updated: 2026-10-26 UTC.

## Goal and current evidence

The target remains a new FPGA image with at least 100 GB/s effective streaming bandwidth, passing 100 MHz timing and measured on the shared U280. No candidate image or target measurement exists yet. The previous goal turn made progress by implementing and verifying the memory layout and replicated bank. This continuation adds a tested board wrapper, actual XO packaging, two-CU link support and completed bank routing. The current checkpoint adds bounded-admission controller results and an RTL issue-rate experiment, with synthesis evidence redirecting implementation toward compact burst engines. The target remains unachieved.

The source audit and existing R40 board/model evidence establish an upstream bottleneck. Three 64-bit core request paths admit at most 2.4 GB/s at 100 MHz, before protocol overhead. Three 256-bit outlets provide 9.6 GB/s in each AXI data direction. The prior ports experiment measured no gain from one to three outlets. Its model attributed contention to the home engine and core dependency waits; this attribution is not a new board measurement.
