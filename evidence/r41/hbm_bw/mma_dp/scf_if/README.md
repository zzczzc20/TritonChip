# Conditional integer division in the compiler

`doc/engineering_discipline.md` applies. This is software work after the frozen run-2 image; it does not alter the running implementation.

The result-producing `scf.if` importer previously if-converted pure branches and refused division/remainder, because speculating both arms could execute an invalid division or an unselected loop. On a `matrix_dp` target, the new path uses a real scalar conditional branch for i32 scalar or single-vector results when either arm contains integer division or remainder. It still refuses nested control flow and the other side effects in `_IFCONV_IMPURE`; other result representations retain the old refusal. It does not recognise benchmark names, shapes or graphs. The existing default-profile path is unchanged by this capability gate.
