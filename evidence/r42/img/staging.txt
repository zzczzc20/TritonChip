  How the parameters reach the cores: tnca_multicore_hbm_xo -> (tnca_multicore_fpga / tnca_multicore_axi / tnca_multicore_shell) -> tnca_top -> tnca_tile -> tnca_core
  (TENSOR_LINE_HALF -> tnca_tensor LINE_HALF; MTX_PIPE -> tnca_matrix OVL; MAC_F32 -> tnca_matrix, tnca_decoder and the capability word). flow/fpga/package_xo.tcl passes
  every TNCA_IMAGE_PARAMS entry as a generic of the kernel; a name the top does not have is an error there. Software: the profile selects the compiler target
  (compiler/targets/tnca-sim-r42-img-lf.json: matrix_f32 set, so an fp32 tl.dot becomes m.mma.f32.async; every other lowering is the default one).
