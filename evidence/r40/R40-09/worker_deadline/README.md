# R40-09 bounded external candidate workers

The candidate callback can now run compilation and native measurement in a separate process under the graph's original deadline. It passes the remaining budget to process wait, kills the owned process group on timeout (including compiler/simulator descendants), and validates a new JSON result containing common-device-clock endpoints. Wall time bounds tuning and never ranks candidates. Existing result/log files are refused; invalid worker results and nonzero exits cannot become measurements. select records worker failure/timeout and does not publish an over-budget result into the persistent cache.

New process tests: 6/6 (success, exit failure, deadline, no overwrite, malformed device endpoints, descendant cleanup). Existing budget/cache/event tests: 14/14. The initial four worker tests were drafted by the user-authorized local Gemini 3.8 Flash High assistant, then reviewed, adapted to the repository clock tag/path and extended before running.

Actual board integration: the isolated worker compiles the unchanged native standard Torch graph `(a+b)*.5`, checks outputs, and measures zero-staging launches using device events. Compilation plus measurement completed within 9.836 seconds of the unchanged 600-second graph budget, with budget_exceeded=false. The recorded event interval is 795 device cycles. This is functional worker integration, not a workload speedup or full R40-09 acceptance. Worker and supervisor sources and raw device events are retained. The loaded image is the single-core hybrid image, not the pending three-core ownership image.

The new --isolated-workers mode in autotune_native_tests.py also exercises the policy/cache on independent RTL workers. It avoids compiling the same baseline graph in the supervisor before recompiling it in each child; candidate compile/measure work remains inside the same 600-second graph deadline. Formal graph execution occurs after selection and outside the tuning launch log. Full real candidate generation, model/holdout performance, cost-model quality and amortization gates remain pending.
